ARES AIOps Architecture

A simulated Mars habitat runs on Amazon EKS. Git is the source of truth, Argo CD keeps the cluster in sync, Prometheus and Grafana watch it, Fluent Bit ships its logs to CloudWatch, and an Ops Copilot built on Claude in Amazon Bedrock explains what is happening when you break it.

How a change and a question flow

  1. You push to main. GitHub Actions runs unit tests and builds both images.
  2. Trivy blocks fixable critical CVEs, then the job assumes a GitHub OIDC role and pushes an immutable :sha tag to ECR.
  3. CI commits the new tag to gitops/values. Argo CD pulls Git (CI never holds cluster credentials) and syncs every app.
  4. Nodes in private subnets pull the image from ECR through the NAT gateway and the S3 gateway endpoint.
  5. Prometheus scrapes /metrics; alert rules cover errors, latency, O₂ level, restarts, OOMKills and CPU throttling.
  6. Fluent Bit tails the ares namespace and writes JSON logs and trace spans to a KMS-encrypted CloudWatch log group.
  7. You open Mission Control over kubectl port-forward and ask a question, or press a chaos button.
  8. Mission Control snapshots pods, events, Argo CD state and Prometheus, then invokes the analyst Lambda with its Pod Identity role.
  9. The Lambda runs Logs Insights queries for errors, slow spans, slowest traces and chaos events.
  10. Claude on Amazon Bedrock returns a structured diagnosis: status, answer, root cause, next steps and evidence.

Infrastructure (VPC, EKS, ECR, KMS, IAM, Lambda) is provisioned by infra.yml with Terraform: plan on every pull request, apply on main behind a protected environment.

Security by design

  • No long-lived AWS keys anywhere: GitHub OIDC for CI, EKS Pod Identity for pods.
  • Three CI roles, each trusted for one context: PR plan (read-only), protected-environment apply, and ECR push to two repositories only.
  • EKS API restricted to your IP, access entries instead of aws-auth, audit logs on, secrets envelope-encrypted with KMS.
  • Nodes in private subnets with IMDSv2 and hop limit 1, encrypted gp3 volumes, SSM instead of SSH.
  • Pod Security restricted, non-root, read-only root filesystem, all capabilities dropped, default-deny NetworkPolicies.
  • Chaos API fails closed behind a random token that never touches Git; Argo CD AppProject limits sources and namespaces.
  • Least-privilege IAM: Fluent Bit writes to one log group, Mission Control can only invoke one Lambda, the Lambda can only query one log group and call Bedrock.
  • Nothing is exposed publicly: every UI is reached through port-forward.
